# v1.1 第八轮：每个动作做完都弹窗提醒（＋响一声）

用户要求：「所有行动完成后要弹出弹窗提醒我已完成」。确认的两个口径：

1. **做完就弹窗**（连保存账号、导入导出、保存取证、补录章节这种小动作也一样）；
   「没填对 / 被拦下来 / 失败」仍然只用几秒就没的短提示，不弹窗。
2. 弹窗出现时**同时响一声并震动**，不看着屏幕也知道跑完了。

## 1. 本来就已经有的部分（没重建）

整套流程 / 只签到 / 只跑订阅 / 同步目录 / 核对订阅清单 / 切号 跑完，`AutomationService.runQueue`
的收尾块已经会弹 `DoneDialogActivity`（盖在屏幕上、带「知道了」和「看运行日志」、锁屏上也显示）。
这轮没动它那套契约（标题/正文/时间/按钮）。

## 2. 这轮加的

| 文件 | 改动 |
| --- | --- |
| `auto/RunReport.java` | 新增纯函数 `ofDone(label, detail)` → 标题「已完成：<label>」、正文一行结果、`allGood=true`；标签为空退化成「刚才那件事」，绝不出现「已完成：null」。 |
| `ui/DoneDialogActivity.java` | 新增 `showDone(context, label, detail)` 便捷入口；新增 `chime()`：先看 `AudioManager.getRingerMode()`，**静音/震动模式下不放声音**，正常模式放系统通知音，随后 200ms 短震（API 26+ 用 `VibrationEffect`，31+ 从 `VibratorManager` 取；更低版本退回 `vibrate(long)`）；`onDestroy` 停掉正在放的提示音；放音/震动失败只记日志不崩；800ms 去重避免同一秒连弹两次响两下。 |
| `AndroidManifest.xml` | 补 `android.permission.VIBRATE`（原来确实没有；普通权限、无授权框）。 |
| `res/values/strings.xml` | +19 条完成标签与结果模板（带 WHY 注释）；布局未改，无新增硬编码中文。 |
| 5 个界面文件 | 14 个「完成点」改用弹窗，见下。 |

### 补上弹窗的 14 个完成点

- 账号页：保存账号、删除账号。
- 二级页：导出运行日志、清理核对记录（「已清理 N 条」）、撤销这条修正、手动补录订阅、删除无账章节。
- 节点探测器：保存取证（「已保存到「文件名」」）。
- 订阅页：导出订阅记录、导入订阅记录、添加小说、**选择目标小说（原来是静默生效，现在告诉你「现在盯的是《X》」）**、删除小说、补录章节（「已登记第 a–b 章」）。

### 故意仍是短提示的（按用户口径）

校验不通过（登录名不能为空、必须填密码、书名不能为空、章节号至少第 1 章、代券花费没填清楚…）、
忙碌拒绝（「有任务正在运行…」）、各类失败（导出/导入/保存/修改失败、运行取证未读取、无障碍未开启…）、
以及「队列已启动，别去动屏幕」这类**开始**通知（完成时另有队列弹窗）。
另有两次**本来就已经是弹窗**、无需改：设置页「选择器自检」结果与「导出内置选择器」成功。
设置页开关的提示（「已开启/已关闭每日自动签到并订阅」）按「效果就在眼前」保留为短提示 ——
要它也弹，一行改动。

## 4. 真机上还要你验的、以及一个取舍

1. 响度/震动手感、锁屏下「弹窗＋提示音」的组合、800ms 去重是否合适 —— 只有装机才知道，不合适我再调。
2. **取舍**：提示音对**定时夜里跑**那趟也会响。不想半夜被吵醒的话，改成「夜间（例如 23:00–07:00）
   只震动不响铃」是一处小改动，说一声就做。
3. `androidTest`（Room 那几条）仍需真机：`.\gradlew.bat connectedDebugAndroidTest`。
