# v1.1 第七轮：主流程三页 UI 重做（步骤 4）

范围（用户确认）：**只重做主流程三页** —— 签到页、账号页、订阅页。二级页（DetailActivity）与设置页不动。
用户的情况：使用者本人操作、手指能点、看得清字 —— 所以不做"极简大字"，而是**信息优先、少层级、
每屏第一行是一句人话**，并保留原有卡片与配色体系（改动风险最小）。

## 1. 三页各变成什么样

**签到页**（`fragment_checkin.xml` + `CheckInFragment.java`）
- 顶部新增 20sp 大标题行「今天」：一句人话答完「跑没跑、成了几个、订了几章」——
  例如「今天：8 个号 · 签到 8/8 · 新订阅 3 章」「今天还没跑 · 8 个号待签到」。
- 主按钮「跑今天的整套流程」占满宽度；次要行＝「只签到」「停止」；暂停时的「继续」「跳过此账号」仍在原来的横幅里。
- 入口卡变成三张：**今日状态 / 运行日志 / 账本核对（存疑 N 条）**，都保持「标题 + 一句摘要 + 箭头」。
- 底部仍是各号累计（二级页）。

**账号页**（`fragment_accounts.xml` + `AccountsFragment.java`）
- 顶部新增总览卡：一行「6 个启用 · 2 个停用 · 代券合计 340」＋三档状态点。
- 每行 = 名字 + **一句状态**（能不能自动跑 · 代券余额 · 上次签到 · 菠萝包昵称（与备注名不同时））+ 右侧「切换账号」。
- 行点击=编辑、长按=删除、「切换账号」按钮（v1.1 第六轮加的，带确认弹窗）行为一个字没改。

**订阅页**（`fragment_subscription.xml` + `SubscriptionFragment.java`）
- 最上面是目标小说一行。
- 新增「今天要做的三件事」卡：**同步目录 / 核对订阅清单 / 只跑订阅**，每颗按钮下面紧跟它的摘要
  （目录什么时候扫的 / 上次核对结论 / 下一章买哪一章、建议用哪个号）。
- 账本入口重排：**各号累计 → 已登记章节 → 核对记录与存疑**。
- 选书、加书、加章、导入/导出挪到底部「更多」一行（功能都在）。
- 最后一行是花费/上限摘要。

**共用**：新增 `Blb.Text.Headline`（20sp 粗体）；`Blb.Text.Line2` 从 14sp 提到 15sp（正文 ≥15sp 规则）。
新增 5 条 strings（都带 WHY 注释），三份 layout 里没有硬编码中文（已 grep 验证）。

## 2. 新逻辑都放进可单测的纯函数

按仓库既有做法（这个项目没有 Robolectric，界面代码测不了），所有能算错的地方都抽成
不依赖 Android API 的类，并配 JVM 单测：

| 新类 | 干什么 | 测试 |
| --- | --- | --- |
| `ui/TodayHeadline` | 顶部那句「今天…」+ 三档颜色 | `TodayHeadlineTest`（9 条） |
| `ui/TodayPurchases` | 今天真实新订阅了几章（按章去重、不算免费章，窗口截断时说「≥N 章」） | 同上 |
| `ui/AccountOverviewText`、`ui/AccountRowText` | 账号页总览句与每行那一句 | `AccountsPageTextTest`（12 条） |
| `ui/SuspectSummary`、`ui/SpendSummary` | 存疑入口摘要（签到页与订阅页共用，措辞与以前一致）、花费/上限摘要 | `EntrySummaryTest`（+9 条） |

## 4. 与最初承诺的差异（实施时按实际情况定的）

1. **红色从这三页里消失了**：一级页只用绿=成了 / 琥珀=要人管 / 灰=还没跑；逐个号的红标仍在二级页。
2. 订阅页第二颗动作按钮仍叫**「只跑订阅」**（不改成「自动订阅」）—— 它的确认框和提示语都是这个叫法，
   只改标签会让同一个动作有两种说法。
3. **「只签到」保留**（降级成描边次要按钮，挨着「停止」）：删掉它等于删掉一个真实功能。
4. 「新订阅 N 章」用的是既有的 `observeRecentRows(500)`（没有新增 DAO/Room 查询）；窗口不够时说
   「≥N 章」而不是编一个精确数。「只跑订阅」没有"上次结果"可显示，所以它的摘要写的是下一章计划。
5. `Blb.Text.Line2` 是共享样式，所以二级页列表的第二行也跟着变成 15sp（它的布局没动）。
6. 账号行不再印登录方式（账号密码/微信/QQ/微博），只留「能不能自动跑」——这是"一句话"取舍的结果；
   要恢复成第三行随时可以加回。
