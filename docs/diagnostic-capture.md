# 诊断采样与导出

节点探测器和自动运行取证先顺序遍历一次传入的目标窗口树，将已读属性、父子关系和集合元数据保存成只读副本。目录行证据、订阅明细行证据、完整树文本和手动匹配报告都从这份副本生成，后续生成文本时不会再读取活动节点。业务扫描、页面点击和滚动仍使用原有节点，不使用诊断副本。

订阅明细行证据复用实际采集链路的分类与解析：列出当前快照行序、从零起的 UI 项索引、原文、原始及解析后的金额与币种、未知原因和本屏日期依据。单屏文件不能证明跨屏日期连续性或整份明细完整。运行日志另记录经过连续索引区间证明的日期归属；遇到冲突会同时列出之前的观察和当前观察。

这不是 Android 的原子帧：系统仍可能在这一遍采样期间更新页面。文件开头会明确说明这个限制。采样最多访问 2500 个节点、深度最多 60 层；节点或深度超限、空子项、属性读取异常都会标明。原始 `childCount` 会保留，遍历只使用已采到的子项；读取失败的默认值仅代表未知，不代表已确认的界面属性。

运行取证保存在 App 私有目录，不上传。保存按钮会先固定当前正文，再打开系统文件选择器；返回或 Activity 重建后仍导出点击保存时的正文。文件包含目标页面节点文字、坐标和选择器诊断，供核实此次故障使用。
